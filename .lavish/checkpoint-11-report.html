Historical regressions

The trade-off stayed visible

  • Financial approval moved from rank 4 to rank 3 under neural reranking.
  • Priority notification moved from rank 2 to rank 4 in the same compound case.
  • The dedicated notification case remained Recall@5 1.000 for both rerankers.
  • The expanded financial case did not reach Full@5 with NVIDIA embeddings under either reranker.

Evidence limitations

What remains unclosed

  • Gemini quotas blocked expanded embeddings and most live generation and planning comparisons.
  • Generation used a 14-case stratified sample.
  • The corpus contains only five fictional documents.
  • Hosted trial behavior does not predict dedicated NIM performance or cost.
  • Citation entailment is a conservative lexical check.
  • The 500-character target still needs a synchronized production reindex.
Project freeze

Checkpoint 11 closes the experiment sequence. There is no Checkpoint 12, and no architecture or runtime index change is implied by this report.
